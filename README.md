# Projeto — Consórcio de Motos

## Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica de Desenvolvimento Web, com o objetivo de aplicar conceitos fundamentais da linguagem HTML5 na criação de um site completo e organizado.

O tema escolhido foi consórcio de motos, apresentando informações sobre diferentes modelos de motocicletas, opções de consórcio, valores e características dos veículos.

A proposta principal foi construir o projeto utilizando HTML, explorando elementos semânticos, navegação entre páginas e diferentes recursos multimídia.

## Páginas do projeto

O site é composto por quatro páginas principais:

* **Início (`index.html`)** — Apresentação do site e informações gerais sobre consórcio de motos.
* **Motos (`motos.html`)** — Apresentação de alguns modelos de motocicletas, com imagens, áudio e vídeo.
* **Consórcio (`consorcio.html`)** — Explicação sobre o funcionamento do consórcio e uma tabela com modelos, valores e formas de parcelamento.
* **Sobre (`sobre.html`)** — Apresentação dos objetivos do projeto, vantagens do consórcio e formulário para cadastro.

## Tecnologias utilizadas

* HTML5
* Elementos semânticos (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
* Links para navegação entre páginas
* Imagens
* Áudio
* Vídeo
* Tabelas
* Listas ordenadas e não ordenadas
* Formulários
* Elementos de texto e citações

## Objetivos

O projeto tem como objetivos:

* Praticar a criação de páginas utilizando HTML5;
* Desenvolver uma estrutura de navegação entre diferentes páginas;
* Utilizar elementos semânticos para organizar o conteúdo;
* Trabalhar com imagens, áudio e vídeo;
* Criar e organizar tabelas de informações;
* Utilizar formulários HTML;
* Desenvolver uma estrutura de arquivos organizada;
* Demonstrar os conhecimentos adquiridos durante as aulas.

## Proposta

A ideia do projeto é apresentar, de maneira simples e organizada, informações relacionadas a motos e consórcios. O usuário pode navegar entre as páginas para conhecer os modelos apresentados, consultar uma tabela de valores e entender melhor como funciona a proposta de um consórcio.

O projeto também demonstra como é possível criar uma estrutura completa de site utilizando HTML, sem depender de frameworks ou bibliotecas externas.
